# Building Production-Ready Agentic AI Systems with LangGraph and LangSmith

## Workshop Overview

Large Language Models (LLMs) have rapidly evolved from simple prompt-response systems into intelligent agents capable of reasoning, planning, maintaining memory, using external tools, and collaborating with other agents. As applications become more complex, traditional linear LLM pipelines become difficult to maintain, debug, and scale.

This workshop introduces **LangGraph** and **LangSmith**, two frameworks from the LangChain ecosystem that help engineers build reliable, production-ready agentic AI systems.

Throughout this workshop, participants will gradually build increasingly sophisticated AI applications while learning the architectural principles behind agentic workflows.
