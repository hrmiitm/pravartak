# Sandboxing

Learn how to create disposable environments for experiments, development tools, and system-level testing.

- **LXD sandboxing** — run a full Linux container with resource limits, snapshots, file transfer, and optional hardware devices.

Start with a disposable lab, keep host folders and secrets out of it, and choose a virtual machine or stronger sandbox when code is actively hostile or untrusted.
